# Loading Screen Gold: A Tip in 200 Characters

One sharp, funny loading-screen tip for stressed developers and AI coding agents: the agent read all 4,000 lines of the error log so you don't have to — and the bug is on line 3, written by you.

`main.py` writes the tip to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`).
